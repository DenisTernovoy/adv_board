# Проект "Доска объявлений"

## Описание:

Доска объявлений - это проект backend-части веб-приложения с использованием фреймворка DjangoRestFramework (DRF) для сайта объявлений.

## Установка:

1. Клонируйте репозиторий:

    ```
    git clone https://github.com/DenisTernovoy/adv_board.git
    ```

2. Выберите *Poetry* в качестве интерпретатора.


## Инструкции по работе с проектом

Бэкенд-часть проекта реализует следующий функционал:

- Авторизация и аутентификация пользователей.
- Распределение ролей между пользователями (пользователь и админ).
- Восстановление пароля через электронную почту.
- CRUD для объявлений на сайте (админ может удалять или редактировать все объявления, а пользователи только свои).
- Под каждым объявлением пользователи могут оставлять отзывы.
- В заголовке сайта можно осуществлять поиск объявлений по названию.

Для запуска сервера необходимо выполнить следующее:
1. Проверьте, что активировано виртуальное окружение в среде разработки и установлены все зависимости проекта;
2. Создайте файл .env и заполните все требуемые переменные согласно файлу .env.sample;
3. Установите Docker согласно инструкции с официального источника;
4. После установки Docker в консоли выполните следующую команду:
    ```
    docker compose up --build
    ```
5. Перейдите по ссылке, на котором запускается Ваш сервер. По умолчанию:
    ```
    http://localhost:80/
    ```
6. С документацией к API-сервису Вы можете ознакомится по ссылке:
    ```
    http://localhost:8000/redoc или http://localhost:8000/swagger
    ```
